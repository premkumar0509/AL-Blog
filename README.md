# 🚀 AL Blog

A collection of practical **Microsoft Dynamics 365 Business Central** development examples written in **AL Language**.

This repository accompanies my technical blog by providing complete, working AL examples that developers can download, explore, and use in their own Business Central projects.

Whether you're learning AL or looking for reusable patterns, this repository aims to provide simple, practical, and production-oriented examples.

---

## 📖 Overview

The purpose of this repository is to share the source code behind my Business Central blog posts.

Each article is implemented as an AL extension so that you can:

* 📚 Learn Business Central development through real examples
* 💡 Understand Microsoft-recommended AL practices
* 🧩 Reuse common development patterns
* 🛠️ Test examples directly in a Business Central Sandbox
* 🚀 Accelerate your own Business Central projects

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/premkumar0509/AL-Blog.git
```

Open the project in **Visual Studio Code**.

---

## 📦 Build

Download AL symbols:

```text
Ctrl + Shift + P
```

Run:

```text
AL: Download Symbols
```

Package the extension:

```text
AL: Package
```

This generates the `.app` package.

---

## 🚀 Publish

### From Visual Studio Code

Press

```text
Ctrl + F5
```

or run

```text
AL: Publish
```

to publish the extension to your Business Central sandbox.

### Manual Deployment

You can also upload the generated `.app` file from:

```text
Business Central
→ Extension Management
→ Manage
→ Upload Extension
```
